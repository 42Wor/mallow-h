# Mellow-h: LLM Code Harness & Execution Tool

`mellow-h` is a lightweight, local CLI tool designed to bridge the gap between AI coding assistants (such as ChatGPT, Claude, or local LLMs) and your local codebase. It compiles project files into structured prompt contexts and applies exact, token-efficient search-and-replace changes with built-in backup safety checks.

---

## Key Features

- **Codebase Compiler**: Aggregates your project structure and non-ignored source files into a single context file (`mellow_prompt.md`) to feed directly into your LLM.
- **Accurate Modifications**: Instead of rewriting entire files, `mellow-h` uses specific formatting syntax to apply only the necessary insertions, replacements, or deletions.
- **Safety Backups**: Before any file is created, modified, or deleted, `mellow-h` backs up the original state in a timestamped folder inside `.mellow/history/`.
- **System Protection**: Centralized security checks prevent LLMs from modifying or deleting critical system and configuration files (such as `.gitignore`, `mellow_prompt.md`, `metadata.txt`, or `container.txt`).
- **Execution Log**: Append execution logs and strict-check failures directly to `metadata.txt`.

## Installation

### 1. Build and install globally

Clone or open your project directory in a terminal and compile the program:

```bash
go build -o mellow-h
```

### 2. Move to your system path

Move the compiled binary to a directory inside your system's `PATH` (such as `/usr/local/bin` on Linux or macOS) so you can run it from any folder:

```bash
sudo mv mellow-h /usr/local/bin/
```

## Usage Workflow

### Step 1: Initialize Your Project

From your project's root directory, run:

```bash
mellow-h init -d
```

This command will:

1. Initialize the `.mellow/history/` directory.
2. Create empty `container.txt` and `metadata.txt` templates.
3. Add safety rules to your `.gitignore`.
4. Scan your directory tree and codebase to generate `mellow_prompt.md` (which you can upload or copy-paste directly to your LLM).

### Step 2: Feed Context to your AI Agent

Provide the generated `mellow_prompt.md` to your AI assistant. The system prompt embedded in the file instructs the AI to output codebase edits strictly using the Mellow format rules.

### Step 3: Paste AI Output & Apply Changes

Copy the formatted output generated by the AI agent and paste it into `container.txt`. Then, apply the changes to your project by running:

```bash
mellow-h apply
```

---

## Command Reference

| Command | Description |
| :--- | :--- |
| `mellow-h init` | Installs the basic setup framework (folders, templates, and `.gitignore` safety rules). |
| `mellow-h init -d` or `--codebase` | Scans the codebase, excludes ignored file types/directories, and builds the prompt helper context. |
| `mellow-h apply [file.txt]` | Applies changes defined in the given container file (defaults to `container.txt`). |

## Format Specifications for AI Output

`mellow-h` parses file adjustments block by block. Below are the formats instructions that your AI agent will follow:

### 1. Create a New File

```text
[FILE] path/to/new_file.ext
[CREATE]
<exact lines of code to write>
[END]
```

### 2. Modify an Existing File

```text
[FILE] path/to/existing_file.ext
[SEARCH]
<exact lines of code to find - must match exactly, including indentation>
[REPLACE]
<new lines of code to replace the searched lines>
[END]
```

### 3. Delete a Code Snippet

```text
[FILE] path/to/existing_file.ext
[DELETE]
<exact lines of code to remove>
[END]
```

### 4. Delete an Entire File

```text
[FILE] path/to/file.ext
[DELETE_FILE]
[END]
```

## Configuration & Ignored Files

`mellow-h` safely ignores standard, non-text, and dependency folders.

- **Default Ignored Folders**: `.git`, `.mellow`, `node_modules`, `venv`, `.venv`, `dist`, `build`, `.vscode`, `__pycache__`, `target`.
- **Default Ignored Extensions**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.ico`, `.svg`, `.zip`, `.tar`, `.gz`, `.pdf`, `.exe`, `.dll`, `.dylib`, `.so`, `.bin`, `.mp3`, `.mp4`, `.wav`.
